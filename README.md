# Интернет-спидтест

Простой консольный инструмент для измерения скорости интернет-соединения. Выполняет серию последовательных запросов к указанному ресурсу и вычисляет среднюю скорость загрузки.

## Особенности

- Последовательные запросы к указанному URL
- Автоматический замер времени загрузки
- Расчет средней скорости и общего объема данных
- Опциональная запись результатов в файл
- Поддержка пользовательских настроек через CLI-флаги

## Установка и запуск

```bash
# Установить зависимости
npm install

# Запустить тест скорости с параметрами по умолчанию
node index.js

# Настроить количество запросов и размер буфера
node index.js --requests 20 --buffer-size 2048

# Сохранить результаты в файл
node index.js --output file

# Показать список доступных опций
node index.js --help
```

## Параметры

| Флаг | Описание | По умолчанию |
|------|----------|--------------|
| `--requests=N` | Количество запросов | 10 |
| `--url=URL` | Адрес для тестирования | Тяжёлая картинка Google |
| `--buffer-size=N` | Размер буфера в байтах | 1MB |
| `--output=file` | Записать результаты в output.txt |
| `--save-files` | Сохранять промежуточные файлы |

## Результаты

Пример вывода в консоль:
```
Запрос 1: Время загрузки - 123.45 мс
...
Среднее время запроса: 123.45 мс
Общий объем загруженных данных: 5.67 МБ
Скорость скачивания: 4.56 МБ/с
```

Единицы измерения: время — миллисекунды, объем данных — мегабайты.

## Технические детали

- Использует встроенные модули Node.js для HTTP-запросов
- Поддерживает последовательные запросы
- Обрабатывает сетевые ошибки и таймауты
- Очистка временных файлов при завершении работы

Этот инструмент создан в рамках тестового задания и демонстрирует базовые принципы измерения скорости интернет-соединения.
